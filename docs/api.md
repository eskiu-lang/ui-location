## `<location>`

`<location>`: where the device is, for apps on eskiu-lang/ui. use_location gives a component
the latest position while it is mounted; the platform's location service measures it
(CoreLocation on iOS, LocationManager on Android, navigator.geolocation on the web), after
asking the user for permission the first time.

### LocationStatus

```eskiu
enum LocationStatus { LocationWaiting, LocationReady, LocationDenied, LocationUnavailable }
```

Where a Location stands: waiting for the first position, a position is ready, the user
denied the permission, or the service is off or cannot find the device.

### Location

```eskiu
struct Location {
    int status;
    double latitude; double longitude; double accuracy;
    bool has_altitude; double altitude;
    double speed = -1; double heading = -1;
    int64 time;
}
```

A position. `status` is a LocationStatus; the rest is meaningful once it is LocationReady.
latitude and longitude are degrees, accuracy the radius in meters the position is within,
altitude meters above sea level (when has_altitude), speed meters per second and heading
degrees clockwise from north (-1 when the platform does not know them), time when it was
measured (milliseconds since 1970).

### location_read

A message on the "location" channel into location_latest.

### use_location

```eskiu
Location use_location(bool precise)
```

The latest position while the calling scope is mounted; the scope renders again with each
new one. The first use starts the platform's service (and asks for permission), the last
one to unmount stops it. `precise` asks for the device's best accuracy rather than about a
hundred meters, which saves power; the first component to mount decides.

### location_last

```eskiu
Location location_last()
```

The latest position or failure, without subscribing: what the last component saw.

### location_distance

```eskiu
double location_distance(Location a, Location b)
```

The distance between two positions in meters, over the Earth's surface (haversine, on a
sphere of the Earth's mean radius).
